# Architecture Decision Records

ADRs capture durable production decisions. Create `NNNN-short-title.md` from the format below before implementation when a change affects data storage, compatibility, privacy, security boundary, capacity architecture, deployment topology, or irreversible operations.

```markdown
# ADR NNNN: Title

## Status
Proposed | Accepted | Superseded by ADR NNNN

## Context

## Decision

## Consequences

## Rollout And Rollback
```
